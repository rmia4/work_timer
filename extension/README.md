# Work Timer 크롬 확장 (팝업)

툴바 팝업에서 로그인·회원가입하고, 진행 중인 작업을 보고 일시정지·다시 시작·종료·저장(업무 결과 입력)합니다.
타이머 화면의 작업 폼은 웹앱과 같습니다(작업명, 업무 내용/결과, 목표 시간, 소요 시간 직접 입력, 측정 시작·기록 저장).
팝업 상단 막대에서 타이머·일지·메모·요약 화면으로 이동합니다. 우측 상단 설정(톱니) 버튼 메뉴에서 다크·라이트 모드 전환, 웹페이지 방문(웹앱을 새 탭으로 열기), 비밀번호 변경, 로그아웃을 합니다(테마는 처음엔 브라우저 설정을 따릅니다).
일지 화면에서는 날짜를 옮기거나 작업 캘린더에서 고른 날짜의 기록을 보고, 완료 기록을 수정(타이머 화면 폼으로 이동)하거나 삭제합니다. 일지 화면 위의 "일일 메모"를 누르면 그 날짜의 일일 메모를 봅니다. 요약은 일지에서 고른 날짜의 측정 시간과 하루 활동 시계를 보여 주고, "CSV" 버튼으로 기간을 골라 업무 기록을 CSV 파일로 내보내거나 같은 범위의 AI 요약 프롬프트를 복사합니다(웹앱 통계의 데이터 내보내기와 같습니다).
메모 화면(메모장)과 일일 메모는 웹앱과 같이 추가, 제목·내용 수정(자동 저장), 위·아래 이동, 삭제를 할 수 있습니다. 메모장은 접기·펼치기도 됩니다.
빌드 단계 없이 이 폴더를 그대로 크롬에 불러옵니다.

## 설치 (개발용)

1. 확장은 Vercel 서버(`https://work-timer-mauve-seven.vercel.app`)에 연결합니다.
2. 크롬에서 `chrome://extensions`를 열고 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 이 `extension/` 폴더를 고릅니다.
4. 카드에 표시된 확장 ID를 Vercel 프로젝트 환경 변수에 넣고 다시 배포합니다.

   ```
   EXTENSION_ORIGIN="chrome-extension://<확장 ID>"
   ```

5. 팝업을 열어 로그인하거나 회원가입합니다. 팝업과 사이트는 같은 로그인 쿠키를 씁니다(사이트에서 로그인해 두어도 됩니다).
   팝업 로그인·메모·계정 기능에는 서버가 확장 Origin의 쓰기 요청을 허용해야 합니다(웹앱 `trustedOrigin`).

## 다른 서버에 연결

`config.js`의 `APP_ORIGIN`과 `manifest.json`의 `host_permissions`를 같은 주소로 바꾸고, 그 서버의 `EXTENSION_ORIGIN`에 확장 ID를 설정합니다.
확장 ID는 폴더 경로가 같으면 유지됩니다.
