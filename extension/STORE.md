개발자 대시보드의 각 칸에 그대로 붙여 넣는다. 제출용 zip에는 넣지 않는다.

## 스토어 등록정보

- 카테고리: 생산성(Productivity)
- 언어: 한국어

### 짧은 설명 (manifest `description`과 같음)

업무 기록 타이머를 팝업에서 보고 조작합니다.

### 상세 설명

Work Timer 웹앱(work-timer-mauve-seven.vercel.app)의 업무 타이머와 기록을 브라우저 툴바 팝업에서 바로 다룹니다.

- 타이머: 작업명·업무 내용·목표 시간을 적고 측정을 시작하고, 일시정지·다시 시작·종료·기록 저장을 합니다.
- 일지: 날짜별 업무 기록을 보고 수정·삭제하며, 작업 캘린더와 일일 메모를 확인합니다.
- 메모: 메모장과 일일 메모를 추가·수정·정렬·삭제합니다.
- 요약: 하루 측정 시간과 활동 시계를 보고, 기간을 골라 CSV로 내보내거나 AI 요약용 프롬프트를 복사합니다.
- AI 연결: Claude·Codex에 Work Timer를 연결하는 안내 화면을 열고, 연결된 AI 앱 목록을 보거나 연결을 해제합니다.
- 계정 설정: 비밀번호를 바꾸고, 업무일지·메모·일일 메모를 일괄 삭제하거나 계정을 삭제합니다.
- 다크·라이트 테마를 지원합니다.

Work Timer 계정이 필요합니다. 팝업에서 바로 회원가입·로그인할 수 있고, 웹앱과 같은 계정·기록을 씁니다.

## 개인정보 보호 탭

### 단일 목적

Work Timer 웹앱의 업무 타이머와 업무 기록·메모를 툴바 팝업에서 조회하고 조작합니다.

### 권한 사용 이유

- 호스트 권한 `https://work-timer-mauve-seven.vercel.app/*`: 확장이 연결하는 Work Timer 서버입니다. 로그인하고 업무 기록·메모를 조회·저장하는 API를 이 주소로만 호출합니다. 다른 사이트에는 접근하지 않습니다.
  (AI 연결의 "claude.ai 열기"는 claude.ai 커넥터 추가 화면을 새 탭으로 열 뿐이며, 주소에 Work Timer 서버 주소 외의 사용자 정보는 담지 않습니다. 추가 권한이 필요 없습니다.)
- `alarms`: 1분마다 위 서버에서 오늘 업무 기록과 메모장을 미리 받아, 팝업을 열 때 기다리지 않고 바로 보여 주는 데 씁니다.
- `storage`: 미리 받은 오늘 업무 기록과 메모장을 이 브라우저에만 저장합니다. 로그아웃하면 지웁니다.

### 원격 코드 사용

아니요. 모든 스크립트는 확장 패키지에 들어 있고, 외부 코드를 내려받아 실행하지 않습니다.
